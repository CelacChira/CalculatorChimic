**Calculator Chimic**

O aplicație Android, scrisă în Java, care ajută la calcule chimice de bază: masă molară, procente de masă, concentrație molară și informații despre elementele chimice.

Aplicația are 3 file (tab-uri):

1. **Masa Molară**: introduci o formulă chimică (ex: `H2O`, `NaCl`) și afli masa molară, plus procentul de masă al fiecărui element din formulă.
 <img width="200" height="400" alt="image" src="https://github.com/user-attachments/assets/8b83951b-f7aa-4b8b-99f2-d99701eda9f0" />

2. **Concentrație**: introduci masa substanței, volumul soluției și masa molară, și afli concentrația molară.
 <img width="200" height="400" alt="image" src="https://github.com/user-attachments/assets/a31d6807-3483-40f7-9c1f-b493e7d2582f" />

5. **Tip și Stare**: introduci simbolul unui element (ex: `Fe`) și afli ce tip de element este (metal, nemetal, gaz nobil etc.) și în ce stare de agregare se află la temperatura camerei.
<img width="200" height="400" alt="image" src="https://github.com/user-attachments/assets/502fc1b6-47ea-4472-af77-347486cc3cff" />


**Tehnologii/ instrumente utilizate**

- **Java** _limbajul de programare_
- **Android Studio / Gradle** _pentru construirea aplicației_
- **TabLayout + ViewPager** _pentru cele 3 file din aplicație_
- **JSON** _pentru datele despre elementele chimice_

**Scopul acestui proiect**

Am realizat această aplicație pentru a ajuta o prietenă care studia la facultatea de chimie
